# WordPress.org Compliance Review - 2026-05-15

## Scope

This review covers the current Sentient Forms WordPress plugin checkout on
`option2-migration-import-foundation`, the generated WordPress.org-style package at:

`../temp/2026/05/15/000259-wporg-package/sentient-forms`

It also covers the public generated-asset source repository created for release `v0.1.0`:

`https://github.com/TWP-Technologies/sentient-forms-wp-plugin/tree/v0.1.0`

- WordPress.org Detailed Plugin Guidelines: https://developer.wordpress.org/plugins/wordpress-org/detailed-plugin-guidelines/
- WordPress.org planning/submission guide: https://developer.wordpress.org/plugins/wordpress-org/planning-submitting-and-maintaining-plugins/

- WordPress Plugin Check: https://wordpress.org/plugins/plugin-check/

## Current Result

The exact package passes static WordPress.org package checks, the official readme
validator, local license/package scans, and WP-CLI Plugin Check. It is not ready
to submit as a final WordPress.org listing because two release-critical external
dependencies are not live yet:

- `https://sentientforms.com/terms` returns 404.
- `https://sentientforms.com/privacy` returns 404.
- `https://api.sentientforms.com/v1/health` returns 404.
- The production CPS host is configured in GitHub but cannot deploy until
  `/var/www/vhosts/twp.tech/production.env`, a production database, and a public
  proxy route exist.
