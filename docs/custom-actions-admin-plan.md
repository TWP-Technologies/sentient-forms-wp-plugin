# Retired Custom Actions CPS Proxy Plan

Status: retired

This document is a historical marker for the pre-local-first design in which WordPress Custom Actions and Action definitions were expected to be proxied from CPS. That design is not current guidance and must not be implemented.

The plugin Action Catalog and local WordPress repositories now own executable Action definitions, Custom Actions, and Form Mappings. CPS receives opaque Action codes only as managed-execution correlation and accounting metadata. Current implementation guidance lives in `AGENTS.md` and the private workspace Action references.

The original proxy work breakdown remains available in Git history for historical investigation.
